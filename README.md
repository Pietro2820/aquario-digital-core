# 🐟 Missão Aquário Digital

## Descrição do Projeto
Sistema core para monitoramento e gestão da qualidade da água do ecossistema do Aquário Digital.

## Camadas do Ambiente (GitFlow)
Este repositório utiliza o fluxo de versionamento corporativo em três etapas principais:
* **`develop`**: Ambiente de desenvolvimento contínuo e integração de novas features.
* **`stage`**: Ambiente de testes/homologação (QA) para validação antes do release.
* **`main`**: Ambiente de produção, contendo apenas código estável e testado.
